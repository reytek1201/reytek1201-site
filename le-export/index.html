Export to reytek

Copies a Last Epoch Tools build as data for the Gaming page. It only reads the page you are looking at and sends nothing anywhere.

Export to reytek
  1. Drag the button above onto your bookmarks bar.
  2. Open your build on lastepochtools.com/planner and keep the tab in front.
  3. Click the bookmark and wait about a minute for the "Copied" note.
  4. Back office, Characters, the Last Epoch character, paste into "Last Epoch build data", save.

It reads the planner's current layout, so if the site changes, it may need an update.
